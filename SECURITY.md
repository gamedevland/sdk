# Security

Security fixes target the current releases of `@gamedevland/engine` and `@gamedevland/vite`.

Please report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/gamedevland/sdk/security/advisories/new).
Include affected versions, a minimal reproduction and the potential impact. Do not publish credentials
or working exploits in a public issue. No response-time or support SLA is promised.
